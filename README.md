### Overview
This project analyzes various datasets to reach different goals.
### Repository Contents

main.ipynb: The main Python notebook containing:

SQL query.

Pandas code to validate the query and process the data.

Visualizations to display the data.

Explanations of the process and results.

datasets/: Directory for Data Set 1, 2, 3, 4, 5 and 6 (not included in this repo for privacy).

Results/: Directory for saved results for all the processed data.


### Prerequisites:

Install Python 3.12.1
Install required libraries: pandas, matplotlib

```
pip install pandas matplotlib 
```


Ensure Data Set 1, 2, 3, 4, 5 and 6 are available in CSV format.


## Running the Notebook:

Open main.ipynb in Jupyter Notebook or JupyterLab.

Update the file paths to point to all the datasets.

Run the cells sequentially to:

Load and join the datasets.

Compute all the processes.

Generate visualizations.

Review the results and insights.
